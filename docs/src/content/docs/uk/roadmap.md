## ✅ Зроблено у версії 0.1.0

- Нова назва, логотип і вікно налаштувань із вкладками, пошуком та пресетами.
- Пресети: Performance, Balanced, Beauty.
- Вікно підписок із пошуком та мітками нових відео.
- Палітра команд (<kbd>Ctrl</kbd>+<kbd>K</kbd>).
- Сітка головної сторінки за шириною вікна; вимкнення розмиття під час прокрутки.
- Підсвітка коментарів, чипи, фільтр спаму та налаштування з 2.9.0, покриті E2E-тестами на порівняння.
- Діагностика: час проходів, ширина сітки, структура бокового меню, layout shifts.

## 🚀 Далі

1. **Модульні фічі.** Перенести кожну функцію в `src/features/<name>/` за контрактом `defineFeature`. Результати E2E-тестів мають збігатися.
2. **Стан селекторів.** Діагностика показуватиме кількість знайдених елементів для кожного селектора YouTube, щоб одразу виявляти зміни розмітки.
3. **Дані розпізнавання за мовами.** Підписи кнопок, суфікси лічильників та фрази спаму, згруповані за мовами.
4. **Розширення браузера** для Chrome та Firefox із єдиної кодової бази на [WXT](https://wxt.dev): синхронізація налаштувань через `chrome.storage`, спливаюче вікно та сторінка опцій.

## ⚠️ Не перевірено з авторизованим акаунтом

Тести виконуються на макетах та публічних сторінках YouTube. Наступні частини залежать від розмітки для авторизованих користувачів:

- головна сітка з персональною стрічкою;
- вікно підписок та крапки нових відео;
- кнопка Ask.

Якщо щось працює некоректно, надішліть звіт через **Copy diagnostics** у налаштуваннях.
