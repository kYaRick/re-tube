## 🛠️ Стек технологій

| Задача | Інструмент |

## 📁 Структура

```
src/
  core/        конфіг, налаштування, селектори, рантайм, DOM-хелпери
  features/    одна тека на фічу: index.ts + style.css
  ui/          панель налаштувань, палітра команд, канали
  main.ts      точка входу
legacy/        однофайловий скрипт версії v2.9.0
tests/         unit (Vitest) та e2e (Playwright)
docs/          сайт документації
```

## 🔄 Статус міграції

Скрипт версії v2.9.0 працює без змін із теки `legacy/` через `src/main.ts`.
Фічі переносяться до `src/features/` по одній. Коли фіча перенесена, її код видаляється з legacy-файлу в тому ж коміті, а E2E-тести мають видавати однаковий результат.

## ⚙️ Рантайм

1. На етапі `document-start` модуль класичного макета блокує прапорці експериментів YouTube. Це виконується до того, як YouTube їх прочитає.
2. Налаштування завантажуються з `localStorage` та проходять через `normalizeSettings` (міграції за `_v`).
3. `MutationObserver` та `ResizeObserver` планують прохід. Кожен прохід викликає `pass()` для всіх фіч у порядку масиву `src/features/index.ts`.
4. Кожен хук обгорнуто в `try/catch`. Помилка в одній фічі записується в діагностику й не зупиняє інші.

## 🎯 Селектори

Усі CSS-селектори YouTube зібрані в `src/core/selectors.ts`. Коли YouTube змінює розмітку, починайте перевірку з цього файлу. Кнопка **Copy diagnostics** звітує кількість знайдених елементів.

## 📌 Правила

- Код, коментарі, назви налаштувань і підказки пишуться англійською. Кирилиця дозволена лише в даних розпізнавання (фрази спаму, підписи кнопок, суфікси лічильників).
- Створюйте DOM через `h()` та `icon()`. YouTube застосовує Trusted Types, тому `innerHTML` не працює. Плагін Biome блокує його використання.
- Зберігайте префікс класів `ytc-` та ключ сховища `ytc:settings:v2`. Їх зміна зламає збережені налаштування користувачів.
