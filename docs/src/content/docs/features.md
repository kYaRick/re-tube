## 🎬 Classic watch layout

YouTube tests a new watch page with the description and comments in a side panel.
Re-Tube turns off the experiment flags for that layout at `document-start` and keeps the classic one: description and comments under the video, recommendations on the right.

## 💬 Comments

- Accent bar on comments by the channel owner, the pinned comment and creator-hearted comments.
- "Top" and "Popular" chips by like count. Thresholds are in the panel.
- Search box above the comments.
- Spam filter and your own stop words. A hidden comment opens with one click.
- Highlight words.

## 🎨 Presets

Performance, Balanced and Beauty set the visual effects in one click. See [Presets](../presets/).

## 📺 Subscriptions window

**Show more** under your subscriptions opens every channel in one searchable window, new videos first. See [Subscriptions window](../subscriptions/).

## ⌨️ Command palette

<kbd>Ctrl</kbd>+<kbd>K</kbd> finds any setting or action by name. See [Command palette](../command-palette/).

## 🤖 Ask button

When YouTube moves the AI "Ask" button into a menu, Re-Tube puts it back under the video.

## 🛡️ Feeds

- Hide Shorts everywhere.
- Hide Playables, "Explore more topics", "Watch together", news and post shelves.
- Hide any section by its heading text.

## 📐 Video grid

Set the number of videos per row on Home: automatic by card width, a fixed number, or YouTube's default.

## 📱 Portrait mode

On vertical screens the watch page becomes one column. Comments can collapse to a few threads with a "Show all comments" button.

## 👁️ Watched videos

A "Watched" badge on fully watched videos. Watched videos can be dimmed.

## ✨ Fluent look

Acrylic surfaces, layered cards and a light that follows the cursor.

## 🔧 Extension toolbars

Toolbars that other extensions add under the player (for example Enhancer for YouTube) no longer cover the video title.
